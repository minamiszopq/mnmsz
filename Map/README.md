# MapApp

SwiftUIとMapKitで作成したiOS向け地図アプリです。

## Features

- 場所や施設の検索
- 現在地への移動
- 標準・航空写真・ハイブリッド表示の切り替え
- OpenStreetMapのデータを利用した高速道路の強調表示

## Requirements

- Xcode 17以降
- iOS 26以降

## Getting Started

`MapApp.xcodeproj` をXcodeで開き、シミュレータまたは実機で実行してください。現在地を利用する場合は、位置情報の使用を許可してください。

## Data Attribution

Highway data is provided by [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) through public Overpass API servers.
