# 仕様確定事項(企画仕様書への追記)

2026-09-21 確定

## データモデル
- 締切・面接日時は `Events` テーブルに分離(企業 1 : N 予定)。一覧の「次の締切日」は未来の予定で最も近いもの。
- 選考状態マスタに `category`(entry / inProgress / offer / closed)を持たせ、ホームのタブはカテゴリで分類。自由追加の状態もいずれかに属する。初期状態に「辞退」を追加。
- 状態変更は `Logs` に自動記録(メモと同じ時系列に表示)。
- 業界はユーザーが追加可能、1社に複数付与可(`Industries` + `CompanyIndustries`)。

## 挙動
- 締切強調の日数は設定で変更可能(初期値 3日)。
- 締切のない企業は「締切が近い順」ソートで末尾。
- 通知タイミングは複数選択可。企業ごとの設定が全体設定より優先(`Companies.useCustomReminders` + `CompanyReminders`)。
- MVP では Notion 連携ボタンは表示しない。
- 削除は Undo 可能(`Companies.deletedAt` によるソフトデリート → 後で物理削除)。

## 技術
- Flutter / drift(SQLite)/ riverpod / flutter_local_notifications + timezone / url_launcher / csv / file_picker / share_plus / shared_preferences
- 全体設定(通知ON/OFF、既定リマインド、強調日数、テーマ)は shared_preferences に保存。

## CSV
- 1企業=1行。予定・メモは1セル内に改行区切り。
- インポート時、同名企業は上書きせず「スキップ / 追加」を選択。
- UTF-8 BOM付きで出力(Excel対策)。
- 列: 企業名 / 選考状態 / 業界 / マイページID / マイページURL / 予定 / 通知設定 / メモ / 登録日。インポートは「企業名」列のみ必須で、列の順番は自由・別名(会社名、ステータス、業種など)も可。
- 予定は「2026/10/01 12:00 締切 ES提出」形式(時刻省略時は12:00)。メモは「[日時] 本文」で区切り、状態変更は「【状態変更】A → B」。
- 通知設定は「共通」「なし」または「前日・1時間前」のような列挙。
- インポートで未知の選考状態は「選考中」分類で、未知の業界はそのまま追加。
- インポートは UTF-8 のみ対応(Shift_JIS は非対応、エラーで案内)。

## デザイン
- ブランドカラー: 落ち着いたインディゴ(seed `#4F5BD5`、Material 3 の配色を生成)
- ライト: 薄く色づいた背景 + 白いカード / ダーク: 暗い背景 + 一段明るいカード。カードは枠線なし・角丸16
- 選考状態バッジ: エントリー=スレート、選考中=青、内定=緑、終了=グレー(`lib/theme.dart` の `statusColors`)
- 締切の強調: カード左端の赤い帯 + 赤い残り時間ピル。お祈り・辞退の企業は薄く表示
- フォントは端末の標準(iOS はヒラギノ)
- 見た目の確認: `flutter test screenshot/ --update-goldens` で `screenshot/out/` に主要画面の PNG を出力(macOS のみ)
